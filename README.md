## 📖 About The Project
The rapid advancement of artificial intelligence has led to a surge in AI-generated media. However, the exact textual prompts used to create these generations are often lost in the comments of traditional social media apps like Instagram or Discord. 

**ReGen** is a dedicated mobile social network specifically built for AI creators. It bridges the gap between art and technique by seamlessly linking high-quality AI-generated images and videos with the exact text prompts used to create them. ReGen allows users to discover, copy, and learn from other creators in a dynamic, real-time environment.

---

## ✨ Core Features
* **Authentication & Profiles:** Secure email/password login, password recovery, and customizable user profiles with avatars and banners.
* **Infinite Image Feed:** An "Instagram-style" scrollable home feed to view, like, and comment on AI-generated images in real-time.
* **Vertical Video Feed:** A "TikTok-style" immersive video feed designed specifically for AI-generated video content with prompt overlays.
* **Seamless Prompt Sharing:** Upload media and attach the exact AI prompt. Prompts are displayed cleanly for easy discovery and copying.
* **On-Device Search:** Instantly filter posts and videos by searching for specific prompt keywords or titles.
* **Dynamic Theming:** Built-in Light and Dark mode toggles controlled via state management.

---

## 🛠️ Built With (Tech Stack)
* **Frontend:** Flutter & Dart
* **Backend:** Firebase (Authentication, Cloud Firestore)
* **Image Hosting:** ImgBB API (Multipart HTTP Requests)
* **Video Hosting:** Cloudinary REST API
* **State Management:** Provider
* **Version Control:** Git & GitHub
